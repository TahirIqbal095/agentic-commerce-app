# Issue tracker: Local Markdown

Issues and specs live as Markdown files in `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- The specification is `.scratch/<feature-slug>/spec.md`
- Implementation issues live under `.scratch/<feature-slug>/issues/`
- Triage state is recorded with a `Status:` line
- Comments are appended under `## Comments`

When a skill says “publish to the issue tracker,” create the relevant file
under `.scratch/<feature-slug>/`.
